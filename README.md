# T-Web-Ferruad-Russo-NUOVO
App web per il progetto del corso tecnologie web 2025/26

## Struttura iniziale
- Frontend React + TypeScript + Vite in `frontend/`
- Backend Spring Boot in `backend/`

## Come iniziare
1. Frontend
   - `cd frontend`
   - `npm install`
   - `npm run dev`
2. Backend
   - aprire il progetto in `backend/` con un IDE Java o avviare l'applicazione Spring Boot da `TWebBackendApplication`
   - l'API sarà disponibile su `http://localhost:8080`

## Requisiti già inclusi
- Login/logout semplificato
- 2 tipologie di utenti (`ADMIN`, `USER`)
- 8+ componenti React
- 2 form con richieste POST
- API REST con più route e 6+ entity
